# Foreword

An Android (MAUI) app — formerly DailyLoader, renamed in P9 — that delivers a morning brief (top news plus the NYT
crossword) to a reMarkable tablet every morning, and reads hand-written notes
back into Google Calendar/Tasks. Credentials are entered in-app on the Settings page.

- Tests: `dotnet test Foreword/Foreword.Tests/Foreword.Tests.csproj -p:ForewordTfms=net10.0`
- APK builds in CI via `.github/workflows/build-android.yml`
- UI follows the repo-wide Paper & Ink design bible (`DESIGN.md` at the repo
  root); tokens live in `Foreword.Android/Resources/Styles/DesignTokens.xaml`
  and the launcher icon is generated by `Tools/IconStudio`.

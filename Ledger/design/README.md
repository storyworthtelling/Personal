# Index design book — committed copies

The Gate 3 mockups for P11, copied out of the published design book
(https://claude.ai/artifact/PEohqNDRai19shxdphibaA) so the build never depends on a link.

- `mockup-NN.html`: one mockup as a standalone page, with the book's own CSS. Paste the section
  verbatim into a UI task's brief (see `../INDEX-P11-PLAN.md` §2).
- `mockup-NN.png`: its render (headless Chromium, 1400px wide).
- `index-design-book.html`: the whole book, including the decision ledger (D01–D162). The icon-concept
  gallery's images live only in the published artifact.
- The cover painting is `/Branding/index-cover.png`.

These are copies, not the source of truth: if the published book changes, re-export them.

Every name, figure, date and card number in these mockups is invented (fictional lenders, round-ish amounts, made-up masks), and the chart geometry is drawn from the synthetic history fixture; they describe the SHAPE of the owner's finances, never the values.

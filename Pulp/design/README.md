# Pulp design book — committed copies

The gate 3 mockups for P12, copied out of the published design book
(https://claude.ai/artifact/M5cdj33HaqxnXsdvv2bu4N) so a build never depends on a link.

- `mockup-NN.html` — one approved screen as a standalone page with the book's CSS; fonts load from
  `/Fonts`. Paste the section verbatim into a UI task's brief (see `../PULP-P12-PLAN.md`).
- `mockup-NN.png` — its render (headless Chromium, 1400px wide).
- `pulp-design-book.html` — the whole book, including the cover and colour rounds.
- `covers/` — every cover study; the chosen one is `study-r3-04.jpg` (also `p4.jpg`, the name the
  book uses). `posters/` — the invented key art the screens show.

Log loop reader

The log loop reader is a private maintenance tool for one person's own apps, the storyworthtelling apps in this repository. Once a week those apps upload their encrypted diagnostic logs to their owner's Google Drive. The reader downloads those files, decrypts them and summarises what went wrong, so that bugs can be found and fixed.

It asks Google for one permission, drive.readonly, which lets it read files in Drive and nothing else: it cannot change, share or delete anything. It is used only by the owner of the apps and is not offered to anyone else.

The source code is public in the Personal repository on GitHub (Tools/LogLoopReader).
